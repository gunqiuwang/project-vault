# 剧本库

两部古风人文短剧和一部都市群像剧的全部剧本材料。

| 文件夹 | 作品 | 体量 |
|---|---|---|
| [`yi/`](yi/) | 《驿》The Last Post Station:唐贞元三年,河西陷落后的边塞驿站,一个老驿长和一个来拆驿的少年书吏 | 10 集加尾声,562 个镜头 |
| [`jieqi/`](jieqi/) | 《二十四节气》鹭浦一年:南宋太湖南岸的水乡小村,八岁的阿禾数着节气等爹回家 | 24 集,326 个镜头 |
| [`gaochu/`](gaochu/) | 《高处》:2008–2027 年的深圳,一场工地坠亡之后十六个普通人的十五年 | 小说 16 章加序章、尾声;12 集剧本;120 个关键镜头 |

《驿》和《二十四节气》都包含:分场剧本与全部台词、分镜表、逐镜首帧与图生视频提示词、按 MiniMax H3 工作流写的动画版分段提示词,以及生成这些文件的脚本。《高处》包含小说、剧本、分镜与生成提示词。各自的说明见文件夹里的 README。
