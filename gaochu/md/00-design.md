# 《高处》总体设计 · 第三版(群像版)

## 这一版改了什么

第三版把《高处》改成一部长时间跨度的群像小说,质感参照东野圭吾《白夜行》那一类作品:冷静、克制、很暗,真相要读者自己从一章一章的碎片里拼出来。故事、人物和情节全部是原创的。

具体做法:

1. **十六年,十六章,十六个讲述者。** 从 2008 年到 2023 年,一年一章。每一章换一个视角人物,大多是被卷进来的普通人:监理、售楼同事、保姆、银行职员、业主、亲戚、孩子。每一章本身是一个完整的小故事。
2. **核心的三个人永远不开口。** 沈既白、林晚、何峻没有自己的视角章节,读者永远看不到他们在想什么,只能从别人的眼睛里看见他们做了什么。
3. **罪行发生在画面外。** 每一章里都有一件“意外”:一个人死了,一个人身败名裂,一个对手突然退出。讲述者看不懂,读者要隔几章才能看懂。
4. **有一个追了十五年的人。** 记者陈默。她是全书唯一一个出现四次的讲述者,也是读者的代理人。
5. **底色更暗。** 第二版里大家都是被收买的;第三版里,有人为了复仇,在暗处用了十五年,把害死弟弟的人一步步送上最高处,再让整座楼塌下来,压在了无数无辜的人身上。

| 第二版 | 第三版 |
|---|---|
| 五个主角轮流讲自己的故事 | 十六个讲述者,三个核心人物没有一章自己的视角 |
| 何峻被收买,沉默十五年 | 何峻接受收买,是为了走进沈既白的身边。他用十五年做沈既白最信任的人,替他摆平每一个麻烦,也替自己收集每一份证据 |
| 林晚为了生活离开周屿,成了沈既白的情人 | 林晚从周屿酒后的一句话里知道了 2008 年的真相。她离开周屿,主动走向沈既白。她和何峻在暗处结成了同盟,从不在人前同时出现 |
| 沈氏暴雷是地产周期的结果 | 暴雷来得那么准、那么狠,是因为有人在里面推了最后一把 |
| 高潮里何峻劝工人下楼 | 讨薪的工人是何峻的复仇造成的。他上楼,面对的是自己十五年的结果 |

## 一句话

2008 年台风夜,何小川从深圳海晏府 31 层坠落。十五年后,海晏府的开发商沈既白站在自己最后一座烂尾楼的 42 层边上,才知道这十五年里他最信任的两个人:一个替他做尽脏活的兄弟,一个跟了他十一年的女人,一直在把他往更高的地方推,好让他摔得更重。

| 项目 | 设定 |

| 类型 | 群像悬疑情感小说 / 剧集 |
| 地点 | 深圳 |

| 剧集 | 12 集,每集约 45 分钟 |
| 结局 | 悲剧收场。核心真相闭合,一部分罪行永远停在“也许” |

## 主题

**白天里有人往上爬,夜里有人在下面托着他,好让他爬得更高、摔得更重。**

复仇和往上爬,用的是同一种手段。何峻和林晚为了让沈既白付出代价,做了和沈既白一样的事:拿别人的命和钱垫脚。到最后,塌下来的楼压住的不是沈既白一个人,是买了理财的退休教师、被欠薪的工人、林晚的亲弟弟,和另一个十九岁的孩子。

全书没有一个人是干净的,但每个人做每件事都有他的道理。读者合上书的时候,应该很难说清自己站在谁那一边。

## 核心三人:读者永远只能从外面看见他们

下面写的是只给作者看的真相。小说里,这些内容一句都不直接写出来,只通过其他讲述者看见的细节透露。

### 沈既白(在白天里的人)

| 项目 | 设定 |
|---|---|
| 生年 | 1980 年 |
| 出身 | 江西赣南农村。1995 年父亲在东莞工地从脚手架上摔下来,腿废了,包工头跑了,一分钱没赔。同济土木系,和周屿是上下铺 |
| 位置 | 2006 年娶许氏地产创始人的独女许知意;2008 年海晏府项目总经理;2018 年岳父去世后执掌许氏,改名沈氏控股;2021 年暴雷;2023 年被捕 |
| 那一夜 | 他下令在台风黄色预警时赶装外立面,让监理拆了安全网,说两个小时挂回去 |
| 真实的他 | 他不是坏人。他对工人比大多数老板都好,给赔偿给得比法定标准多,每年春节自掏腰包给海晏府那一批老工人发红包。他对何峻是真心的:他把何峻当成弟弟,一半是因为愧疚,一半是因为这个人是他身边唯一不要他任何东西的人 |
| 他不知道的 | 何峻是谁的哥哥,他当然知道。他不知道的是,何峻为什么留在他身边 |
| 结局 | 2023 年台风夜,他在云阙 42 层听完了何峻的十五年,走到楼板边上,被何峻拉了回来。他以集资诈骗罪被判无期徒刑 |

### 何峻(在夜里的人)

| 项目 | 设定 |
|---|---|
| 生年 | 1985 年 |
| 出身 | 四川广安农村。2007 年把十八岁的弟弟何小川带到深圳,母亲不同意,他说“我照顾他” |
| 表面 | 2008 年拿了二十八万赔偿,签了保密协议。2009 年接受沈氏给的班组,从此是沈既白最得力的包工头,后来是沈氏工程部所有“难办的事”的经手人:工人闹事、业主维权、拆迁钉子户、对手的把柄。他话少,不喝酒,从不出现在合影里 |
| 真实的他 | 他接受收买的那一天就决定了:他要走到沈既白身边,等。等沈既白爬到最高的地方。他替沈既白摆平每一件事,同时把每一件事的证据都留了一份。他要的不是沈既白坐牢,是他从最高处摔下来,而且知道是谁推的 |
| 他做过的事 | 见下文“真相时间线”。有的确凿,有的永远停在“也许”。最重的一件是 2009 年老郑之死:那天夜里老郑喝醉了,在城中村的河边跟他摊牌要钱,然后掉了下去。何峻就站在旁边。他没有伸手 |
| 和林晚 | 2010 年,林晚来找他。两个人从此是同盟,也许不止是同盟。全书没有一个场景让他们俩同时出现在别人面前 |
| 结局 | 他在 42 层把一切告诉了沈既白,然后在沈既白走向楼板边缘的时候,伸手把他拉了回来。他没有被追究任何罪责,因为没有任何证据。他回了四川,在弟弟的坟旁边盖了一间屋 |

### 林晚(在白天和夜里之间走的人)

| 项目 | 设定 |
|---|---|
| 生年 | 1983 年 |
| 出身 | 湖南邵阳县城,和周屿是高中同学和初恋。高考差三分没上本科线,母亲供弟弟不供她。2003 年来深圳,电子厂,后来做售楼 |
| 表面 | 2008 年海晏府售楼处的销售;2010 年突然离开同居五年的周屿,成为沈既白的情人和营销总监;2018 年出任沈氏财富的总经理和法定代表人;2021 年暴雷,2023 年被判刑 |
| 真实的她 | 2009 年冬,老郑淹死的消息见报那天,周屿喝醉了,把 2008 年那一夜告诉了她,然后哭着睡着了。第二天他什么都不记得。她什么都记得。她离开周屿,不是因为不爱他,是因为她决定去做一件他做不到的事。2010 年她找到何峻,两个人结成了同盟 |
| 她的暧昧 | 她到底是为了替周屿、替何小川讨一个公道,还是只是借这个理由,去拿她本来就想要的东西?全书不给答案。她确实拿了很多:房子、职位、钱。她也确实在 2018 年明知自己会坐牢,还是签下了法定代表人的名字,因为只有她站在那个位置上,暴雷的时候才能把所有的文件送到该去的地方 |
| 她伤到的人 | 她把理财卖给了弟弟林强,卖给了何峻手下的工人,卖给了一个退休的中学老师。她知道这个结构撑不住 |
| 结局 | 她在暴雷后投案自首,认定为从犯,积极退赃,减轻处罚,判六年(羁押自 2021 年 10 月起折抵)。她在法庭上没有提何峻一个字。2027 年减刑出狱,看见马路对面的周屿,上了公交车 |

## 十六章:十六个讲述者

每一章都是一个完整的短篇,讲述者有自己的生活和问题,核心三人只是从他们的生活里经过。“读者看见的”是这一章写出来的;“读者隔几章才明白的”是埋下的线。

### 序章 · 苏拉(2023 年 9 月 1 日)

讲述者:一名消防员。台风红色预警,他在云阙楼下接到报警,楼上有人要跳。他看着一个浑身湿透的男人冲进围挡,说“我是他老板”;十几分钟后,又一个穿大衣的男人从一辆没有牌照的车上下来,也走进了楼梯间。消防员在对讲机里报告:“两个人上去了。”

### 尾声 · 清扫(2027)

讲述者:陈默。2027 年春天,她去监狱门口等林晚出狱,想问她最后一个问题。她看见马路对面站着周屿。林晚出来了,看了一眼周屿,又看了一眼陈默,上了公交车。

陈默在车站追上了她,问:“那天晚上,42 层上,何峻跟沈既白说了什么?”

林晚说:“他说,老郑那天晚上,他没伸手。”

公交车开了。陈默站在车站,想了很久,才明白这句话的后半句:那天晚上在 42 层,他伸手了。

## 写作规则(群像质感)

1. **核心三人不进视角。** 沈既白、林晚、何峻的内心一句不写。他们只通过动作、对话和别人的观察出现。
2. **罪行不在场。** 每一件“意外”都发生在讲述者看不见的地方,讲述者只看见前因和后果。
3. **每章是一个完整的故事。** 讲述者有自己的欲望、困境和结局,核心人物只是经过。去掉核心人物,这一章也应该是一个好故事。
4. **线索必须公平。** 每一个后来的揭示,前面至少有一处细节埋过;每一处细节,后面至少收一次。
5. **时代靠物件说话。** 不写“那一年房价涨了”,写诺基亚、团购券、共享单车、健康码、楼盘广告上的单价。
6. **叙述冷静。** 不用感叹号,不用心理描写替读者解释,情绪留给读者。
7. **不给最终答案。** 林晚为了谁、何峻有没有杀老郑、许知意有没有寄那盘磁带,全书都停在“几乎可以确定”。
