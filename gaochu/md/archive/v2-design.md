# 《高处》总体设计 · 第二版

## 这一版改了什么

第一版的问题是设计感太重:六个人恰好都参与了同一个晚上,关系靠巧合串起来,人物像是为了承载某个社会议题而存在,结局是六个人在台风夜依次上楼认罪,舞台感太强。

第二版按三条原则重写:

1. **关系由处境产生,不靠巧合。** 每两个人物之间的联系,都能用一句话说清“为什么他们必然会遇到”:同学、同乡、同一家公司、上下游的生意。
2. **冲突来自双方都有道理的目标。** 每一个大冲突,都先写清楚两边各自要什么、为什么要、退一步会失去什么。没有人是为了制造矛盾而做决定。
3. **人物先是人,再是议题。** 每个人都有自己的伤口、自我欺骗和说话方式。社会问题是他们生活的环境,不是他们的标签。

| 第一版 | 第二版 |
|---|---|
| 六个人都在 2008 年那一夜做了决定 | 那一夜真正做决定的只有沈既白一个人,周屿是事后作了假证。其他人的“那一份”是之后十五年里各自拿到的好处 |
| 主题:所有人一起把他推了下去 | 主题:一条命被折算成了每个人往上爬的台阶 |
| 何峻送外卖恰好敲开林晚的门、恰好买了她的理财、恰好买了沈氏的烂尾楼 | 何峻拿了赔偿以后成了沈氏的包工头。公司让他拿理财抵工程款,这是地产公司真实的做法,不是巧合 |
| 许知意和陈默因一次撤稿相爱 | 删去。许知意是一个有野心的继承人,她的线是权力和父亲 |
| 何峻跟弟弟换了班去赌球 | 删去。何峻的罪不在那一夜,在之后:他收了钱,签了字,又接了害死弟弟的人的活 |
| 少年闯进查封的房子直播,六个人冒台风上楼 | 2023 年台风夜,一个讨薪的年轻工人爬上烂尾的“云阙”大楼。上楼去劝他的,是欠他工资的包工头何峻 |
| 结局靠追诉时效反转 | 时效只是背景里的一句话。结局靠人物各自的选择 |

## 一句话

2008 年台风夜,深圳一座在建豪宅的安全网被拆了两个小时,十九岁的何小川从 31 层坠落。项目总经理沈既白用钱和关系把事情压了下去,他最好的朋友周屿替他作了假证。十五年里,这条命被折算成了很多人往上爬的台阶:赔偿款、工程合同、升职、婚姻、一套房子。2023 年,沈氏地产暴雷,一个讨不到工钱的年轻工人在台风夜爬上了沈既白最后一座楼的顶层,上楼劝他的人,是何小川的哥哥。

## 核心设定

| 项目 | 设定 |
|---|---|
| 片名 | 《高处》 |
| 类型 | 都市情感群像剧,时间跨度十五年 |
| 地点 | 深圳 |
| 时间 | 2008 年至 2023 年,分四部:2008、2013、2018、2021–2023,另有 2026 年的尾声 |
| 两座楼 | **海晏府**:2008 年在建的南山海边豪宅,何小川坠落的地方。**云阙**:2018 年开工的前海超高层,沈既白要用它证明自己,2021 年停工在 42 层,成了烂尾楼 |
| 小说 | 四部二十四章,加序章和尾声,约 18 万字 |
| 剧集 | 12 集,每集约 45 分钟 |
| 结局 | 悲剧收场,线索全部闭合 |

## 主题

**一条命被折算成了每个人往上爬的台阶。**

2008 年那一夜做决定的只有一个人。真正让这件事变成全剧主题的,是之后发生的事:每个人都从这条命里拿到了一点什么,而且每个人拿的时候都有充分的理由。

| 人物 | 拿到了什么 | 当时的理由 |
|---|---|---|
| 何峻 | 十八万赔偿,后来是沈氏的工程合同 | 父亲要治病,妹妹要读书,家里要盖房 |
| 周屿 | 母亲的手术费不用再还,保住了工作和执照 | 沈既白是他最好的朋友,也是他的恩人 |
| 沈既白 | 项目、岳父的信任、继承权 | 银行贷款到期,项目一停,几百个工人都拿不到钱 |
| 许知意 | 一个成功的丈夫,一家保住了的公司 | 那是她父亲的公司,也是她将来要接的公司 |
| 林晚 | 后来的事业和那套房子,都来自沈既白 | 她不知道那一夜的事,但她知道沈既白的钱从哪里来 |
| 老郑 | 一笔现金,一年缓刑 | 女儿要上大学 |
| 陈默 | 一次升职 | 报社的广告大客户打了电话 |

三层意思:往上爬;爬上去以后发现上面很冷;以及每一级台阶下面都垫着什么。

## 叙事结构

小说和剧集都从 2023 年 9 月 1 日台风“苏拉”登陆的那一夜开始:烂尾的云阙大楼,42 层,一个讨薪的十九岁工人站在没有护栏的楼板边上直播。每一部开头回到这一夜,往前推进一点;正文回到那一部的年份。第四部,两条时间线在 42 层会合。

| 部 | 年份 | 标题 | 时代背景 | 这一部的核心选择 |
|---|---|---|---|---|
| 第一部 | 2008 | 台风 | 金融危机,楼市骤冷,开发商靠预售回款续命 | 要不要说出那一夜 |
| 第二部 | 2013 | 高处 | 房价暴涨,城中村拆迁,人人都想上车 | 爬上去以后,要不要回头 |
| 第三部 | 2018 | 云阙 | 地产加杠杆,房企用理财和商票抵债,许氏创始人去世 | 第二次被收买,收不收 |
| 第四部 | 2021–2023 | 落 | 房企暴雷,理财兑付不了,烂尾楼,讨薪 | 塌下来的时候,谁来扛 |
| 尾声 | 2026 | 清扫 | 云阙复工,改了名字 | 剩下的人 |

## 人物

### 周屿

| 项目 | 设定 |
|---|---|
| 生年 | 1981 年。2008 年 27 岁,2023 年 42 岁 |
| 出身 | 湖南邵阳县城,父亲是县中学的物理老师,一辈子没给人送过礼,一辈子是普通老师。同济大学建筑系 |
| 外在目标 | 设计一栋“好房子”;和林晚在深圳有一个家 |
| 内在需求 | 不再让别人替自己做决定 |
| 伤口 | 2007 年母亲心脏搭桥,手术费十二万,父亲借遍了亲戚。是沈既白一声不响替他交了 |
| 自我欺骗 | “我只是说了一句话,网拆不拆不是我决定的。” |
| 性格 | 温和、能干、怕冲突。他从来不说不,他只是走开 |
| 说话方式 | 话少,爱用“还行”“再说吧”;只有谈到建筑时才会说长句子 |
| 习惯 | 随身带一支自动铅笔,紧张的时候在任何纸上画楼梯 |
| 社会位置 | 技术人员在资本面前的沉默;一个好人怎样一步一步变成共谋 |

**每一部的关键选择:**
- 2008:那一夜十点,他在工地发现安全网被拆了,打电话给沈既白。沈既白说“两个小时,装完就挂回去,风还没到”。他没有向质监站报告。事后调查组问他当晚安全网的情况,他说“是挂着的”。
- 2013:林晚问他“那一年到底发生了什么”。他差一点就说了。他没说。
- 2018:父亲肺癌,他接受了沈既白的邀请,做云阙的总建筑师。第二次被同一个人收买。
- 2023:他主动找到记者陈默,把 2008 年的事原原本本讲了出来。这一次没有人替他决定。

**结局:** 他的证词让沈既白的案子多了一页,但 2008 年的事已经过了追诉时效,他没有被追究。他回到湖南县城,在父亲教过书的中学教美术。2026 年,他去监狱门口等林晚。

### 林晚

| 项目 | 设定 |
|---|---|
| 生年 | 1983 年。2008 年 25 岁,2023 年 40 岁 |
| 出身 | 和周屿同一个县,高中同学,周屿的初恋。高考差三分没上本科线,母亲说家里只供得起一个,弟弟林强读了大专。她 2003 年来深圳,先进电子厂,后来做售楼 |
| 外在目标 | 一套写着自己名字的房子;让家里人不再看不起她 |
| 内在需求 | 被人无条件地选择一次 |
| 伤口 | 那三分,和母亲那句“女孩子读那么多书没用” |
| 自我欺骗 | “等我有了钱,我就自由了。” |
| 性格 | 聪明、能吃苦、会看人、会说话;好笑,对人热络,心里永远在算账 |
| 说话方式 | 对客户是标准普通话,对家里人是邵阳话,对周屿是两种混着说 |
| 习惯 | 手机备忘录里记着每一笔给家里的钱 |
| 社会位置 | 女性靠自己往上爬的路有多窄;原生家庭的索取 |

**每一部的关键选择:**
- 2008:她和周屿住在岗厦城中村,攒钱买房。周屿在那一夜之后变了一个人,酗酒,辞职,什么都不跟她说。
- 2010:弟弟结婚要二十万彩礼,父亲中风。沈既白给了她一个销售总监的位置。她离开了周屿,不是因为不爱了,是因为她再也撑不住一个什么都不肯说的人。不久后,她成了沈既白的情人。
- 2013:父亲去世,回县城奔丧,台风“天兔”把她和周屿困在了一起。她问了那个问题,他没有回答。她回了深圳。
- 2018:沈既白让她出任沈氏财富的总经理和法定代表人。她看得懂这个理财是什么结构,还是接了,还是卖了,包括卖给她弟弟,卖给何峻。
- 2021:理财兑付不了,投资人围住她的办公室。她发现自己从一开始就是被安排好的防火墙。她没有反咬沈既白。

**结局:** 以非法吸收公众存款罪被判三年。她在法庭上没有为自己辩护太多,只说:“我知道我卖的是什么。” 2026 年出狱,看见马路对面等着的周屿。她上了公交车。

### 沈既白

| 项目 | 设定 |
|---|---|
| 生年 | 1980 年。2008 年 28 岁,2023 年 43 岁 |
| 出身 | 江西赣南农村。1995 年,父亲在东莞一个工地从脚手架上摔下来,腿废了,包工头跑了,一分钱没赔。那年他十五岁,在医院走廊里睡了一个月。后来考上同济土木系,和周屿是上下铺 |
| 外在目标 | 永远不再做没有选择的那个人 |
| 内在需求 | 承认自己变成了当年让父亲摔下来的那种人 |
| 伤口 | 父亲的腿,和那个跑掉的包工头 |
| 自我欺骗 | “钱我给了,该做的我都做了。我给他们的,比当年任何人给我爸的都多。” |
| 性格 | 有魅力,对自己人极其慷慨,对挡路的人极其冷静。不贪图享乐,工作到凌晨,吃饭很快 |
| 说话方式 | 普通话里带一点赣南口音,只有在喝醉和打给父亲的时候才会冒出来 |
| 习惯 | 每个月给赣南老家打一笔钱,数额从来不变 |
| 社会位置 | 做题家的阶层跃升;地产高杠杆扩张;资本与权力 |

**每一部的关键选择:**
- 2008:许怀山给他下了最后通牒:月底前拿到海晏府的预售证、回款到账,否则项目交给别人,他这个女婿也就到此为止。银行贷款九月到期。台风黄色预警时他下令赶工,为了装外立面,让监理拆了 28 至 31 层的安全网,说两个小时后挂回去。何小川坠落后,他做了他父亲当年最希望包工头做的事:给钱,给得很多。然后让周屿作证,让岳父打电话。
- 2010:他给了林晚一个职位,后来给了她一段关系。他们是同一类人,在彼此面前不用装。
- 2018:岳父去世,董事会在他和许知意之间选了他。他启动云阙,用理财和商票撑起一个他自己都知道撑不住的现金流。他请回周屿,一半是需要一个信得过的建筑师,一半是想还债。
- 2021:暴雷。他把林晚推到前面,把资产转出去,同时又在最后关头,用自己的钱给海晏府当年那批老工人里还在他手下干活的人发了一个月工资。

**结局:** 以集资诈骗罪被判无期徒刑。宣判那天,他父亲坐着轮椅在旁听席最后一排。

### 许知意

| 项目 | 设定 |
|---|---|
| 生年 | 1979 年。2008 年 29 岁,2023 年 44 岁 |
| 出身 | 许氏地产创始人许怀山的独女。宾大沃顿商学院毕业,比公司里任何一个人都懂财务。父亲从不让她进核心业务,说“女孩子管管基金会就好”。2006 年她嫁给父亲最看重的年轻人沈既白,那是她自己选的:既然父亲只肯把公司交给女婿,她就选一个女婿 |
| 外在目标 | 拿到许氏的控制权 |
| 内在需求 | 不再做父亲的女儿,做她自己 |
| 伤口 | 父亲在她十二岁时说:“你要是个儿子就好了。”他说完就忘了,她记了三十年 |
| 自我欺骗 | “我不需要被爱,我需要的是位置。” |
| 性格 | 冷静、骄傲、幽默感很干。她知道沈既白和林晚的事,早在 2010 年就知道 |
| 说话方式 | 说话不带任何语气词,常常用一句话结束一场谈话 |
| 习惯 | 在基金会办公室里养了一缸鱼,每条都没有名字 |
| 社会位置 | 女性继承人;家族企业的权力 |

**每一部的关键选择:**
- 2008:她知道那一夜出了事,知道父亲打了哪些电话。她什么都没做。那时候她的利益和丈夫一致。
- 2013:她约林晚喝了一次茶。不吵不闹,只是把规矩讲清楚:不许生孩子,不许出现在公开场合,不许碰公司的钱。林晚答应了。两个女人之间从此有了一种奇怪的尊重。
- 2018:父亲去世前把一盘磁带交给她,是 2008 年他和劳动局、报社的通话录音,还有一句话:“哪天他忘了自己是谁,你放给他听。”董事会选了沈既白,她被安排去管云阙的设计审核,在那里和周屿共事。
- 2019:她和周屿之间有了一段两个清醒的成年人才会有的关系。她没有打算让它变成任何东西。
- 2023:沈氏重组,国资接盘,她是唯一一个被各方都接受的许家人。她需要一个足够干净的理由,让自己从沈既白的妻子变成清理沈既白的人。磁带和周屿的证词就是那个理由。

**结局:** 她在周屿公开作证之后放出了磁带,亲手毁掉了父亲的名声,也因此成为新公司的董事长。云阙复工,改名“前海中心”。她最后一次见周屿,两个人都知道她赢了,也都知道她用了什么赢的。

### 何峻

| 项目 | 设定 |
|---|---|
| 生年 | 1985 年。2008 年 23 岁,2023 年 38 岁 |
| 出身 | 四川广安农村,初中毕业就跟着村里人到深圳工地。2007 年,他把十八岁的弟弟何小川带出来,母亲不同意,他说“我照顾他” |
| 外在目标 | 让家里人再也不用求人 |
| 内在需求 | 承认自己卖掉了弟弟的那一夜 |
| 伤口 | 那句“我照顾他” |
| 自我欺骗 | “我拿的是我该拿的,我做的是我能做的。” |
| 性格 | 能干、讲义气、要面子、脾气急。工友都服他 |
| 说话方式 | 四川话,骂人很快,说软话很慢 |
| 习惯 | 每年 8 月 22 日去海晏府楼下抽一包烟,一根一根抽完再走 |
| 社会位置 | 工人的安全与赔偿;层层分包里的欠薪链条;受害者怎样变成下一环 |

**每一部的关键选择:**
- 2008:他不信弟弟是自己不系安全带。他找过记者陈默,陈默来了,写了,稿子没登。父亲肾病,妹妹考上了大学。母亲在电话里说:“拿着吧,小川回不来了。”他签了十八万和保密协议。
- 2009:沈氏的人找到他,问他愿不愿意自己带一个班组。他知道这是什么意思。他接了。
- 2013:他是沈氏的一个小包工头,手下三十个人,在老家盖了三层楼,儿子何念三岁。每年 8 月 22 日,他的卡上会多出一笔钱,没有署名。他以为是沈氏的“封口费”,每年取出来,一分没动,存在一张单独的卡里。
- 2013:那一年的钱第一次不是现金存入,而是转账,流水上只显示“*屿”。他记住了这个字。
- 2018:他的班组进了云阙工地,听见工人叫总建筑师“周工”,全名周屿。他想起小川当年说过“周工教我画画”。他找到周屿,周屿把那一夜的事告诉了他。同一个月,沈氏让所有供应商用理财产品抵三成工程款,不收就换人。他手下八十个工人等着发工资。他收了理财,也收下了沉默,对周屿说:“你的钱我不要了。我那一份,我已经拿过了。”
- 2021:沈氏暴雷。他被欠了六百多万,工人被他欠了一年半工资。他卖了自己在深圳的房子,只够发两个月。
- 2023:台风夜,他村里的年轻人阿勇爬上云阙 42 层讨薪。阿勇是他带出来的,跟当年的小川一样大。

**结局:** 他在 42 层说出了真相,包括他自己。视频传遍了网络。重组方因为舆论,优先结清了他这个项目的欠薪。他拿到了钱,发给工人,知道这笔钱又是从小川身上来的。尾声里,他去了海晏府楼下,第一次没有抽完那包烟就走了。

### 主要配角

## 分部大纲

### 序章 · 苏拉(2023 年 9 月 1 日)

台风红色预警。前海,停工两年的云阙大楼,混凝土框架停在 42 层,四面没有墙。十九岁的阿勇爬上了顶层的楼板,对着手机直播:“我们八十个人,一年半没拿到工资。老板跑了,包工头也拿不到钱。今天不给钱,我就从这里跳下去。”

楼下,警车、消防车、记者。何峻浑身湿透地冲进工地。他是阿勇的包工头,也是欠阿勇工资的人。周屿也来了,他设计了这座楼,知道哪一层的楼梯是通的。

### 第一部 · 台风(2008)

1. **林晚**:海晏府售楼处,她卖着自己一辈子买不起的房子。晚上回岗厦城中村,和周屿挤在八平米的房间里,算还差多少首付。弟弟来电话要钱。
2. **周屿**:驻场建筑师。何小川每天午饭时间来找他学画透视,说以后不想搬砖了。周屿给他一支自动铅笔。
3. **沈既白**:许家的晚饭,岳父的最后通牒,妻子在桌子另一头安静地切牛排。他半夜给父亲打电话,父亲问他吃饭了没有。
4. **何峻**:兄弟俩在城中村吃宵夜,小川说攒够了钱就回老家学画画。那一夜何峻在另一个工地。凌晨三点电话响了。
5. **周屿**:调查组。沈既白在他家楼下等他,没有提那十二万,只说了一句“我需要你”。周屿说了“是挂着的”。回到家,林晚问他怎么了,他说没事。
6. **何峻**:陈默来了,又走了,稿子没有登。母亲在电话里哭。他签了字。9 月底,海晏府首开售罄,沈既白在 31 层开了一瓶香槟。同一天夜里,周屿在岗厦路口的 ATM 前站了很久,把刚取出来的工资存进了一个不是他自己的账户。第二天,何峻的卡上多了一笔现金存入的钱,没有名字。

**第一部结束时,观众知道:** 那一夜是沈既白下的令,周屿说了谎。观众知道那笔钱是周屿打的,何峻不知道。这是全剧第一处让观众比人物先知道的地方。

### 第二部 · 高处(2013)

1. **林晚**:沈氏营销中心的总监,有了自己在龙岗的一套小房子,写着自己的名字。她是沈既白的情人第三年。弟弟在县城开了一家手机店,本钱是她的。
2. **许知意**:约林晚喝茶,讲规矩。林晚一条一条答应。临走时许知意说:“你比他聪明。别让他知道。”
3. **何峻**:沈氏的包工头。他发现自己做的事和当年海晏府的包工头一模一样:赶工期,压成本,该挂的网有时候也少挂一层。他第一次骂人骂到一半停了下来。
4. **沈既白**:回赣南。父亲用一块旧布给他擦皮鞋,问他城里的楼是不是都是他盖的。他说是。他在老家的床上睡了一夜,没有睡着。
5. **林晚 / 周屿**:林父去世,林晚回县城奔丧。台风“天兔”,火车停运。周屿也回了县城,他母亲让他去帮忙。停电的夜里,她问:“那一年到底发生了什么?”他看着她,很久,说:“没什么。”那一夜他们在一起。天亮她走了。
6. **周屿 / 何峻**:前五年,周屿每年 8 月 22 日用现金无卡存款给何峻打钱,不留名字。这一年他手头太紧,凑不出现金,只好用手机银行转账。何峻在流水上第一次看见一个字:“*屿”。

### 第三部 · 云阙(2018)

1. **许知意**:父亲病危,把磁带交给她。父亲去世,董事会选了沈既白。她接下云阙的设计审核。
2. **沈既白**:云阙开工。他知道公司的现金流撑不了三年,但他算过:只要云阙封顶,一切都能重新估值。他让林晚出任沈氏财富的法定代表人。
3. **周屿**:父亲确诊肺癌。沈既白亲自来请他做云阙的总建筑师,年薪是他过去五年收入的总和。他答应了。他在图纸上画了一个他这辈子最好的楼梯。
4. **何峻**:他的班组进了云阙工地。工人们叫总建筑师“周工”。他想起五年前流水上那个“屿”字,想起小川说过的“周工教我画画”。他在工地上找到周屿,把他按在一根柱子上。周屿把那一夜告诉了他。
5. **林晚**:沈氏要求供应商用理财抵三成工程款,何峻坐在她对面签字。她看着他签,想起他是谁。她没有说。弟弟也来买,她犹豫了一下,卖了。
6. **何峻 / 许知意 / 周屿**:何峻对周屿说“你的钱我不要了”。许知意和周屿在云阙的样板层,台风天,两个人都没有回家。

### 第四部 · 落(2021–2023)

1. **林晚**(2021 年 9 月):沈氏财富兑付不了。投资人堵住办公室,弟弟在家族群里骂她骗子,母亲说“你把你弟害了”。她去找沈既白,沈既白说:“你是法人,你得在前面。”她这才明白三年前那个职位是什么意思。
2. **何峻**(2021 年冬):被欠六百万,欠工人四百万。他卖了房,给工人发了两个月。春梅卖了金镯子,给工人买了回家过年的车票。
3. **沈既白**(2022):转移资产,准备出境,在机场被限制出境。他最后一次去赣南看父亲,父亲问他:“那些工人,钱给了没有?”
4. **许知意 / 周屿**(2023 年夏):国资接盘谈判。许知意需要一个理由。她没有开口要周屿的证词,她只是让他知道磁带的存在。周屿去找了陈默。
5. **42 层**(2023 年 9 月 1 日):序章的台风夜接上。何峻爬上 42 层,周屿跟在后面。阿勇站在楼板边上。何峻说出了 2008 年的事,包括他自己签的字和这十五年接的活。直播在线人数涨到三十万。阿勇下来了。
6. **清算**(2023 年秋):陈默发出报道。许知意放出磁带。沈既白被捕。林晚被起诉,她拒绝做沈既白的污点证人。何峻拿到了欠薪。周屿把那支自动铅笔放在何小川的墓前。

### 尾声 · 清扫(2026)

云阙复工,改名前海中心,每一层都挂着安全网。何峻是这个项目的班组长之一,他不再自己包活了。林晚出狱,马路对面站着周屿。她看着他,上了公交车。周屿没有追。公交车开过海晏府,林晚看着窗外 31 层那一排窗户,有一扇开着。

## 亲密戏的处理

五场,每一场都改变一段关系。小说用文学手法写气氛、动作的片段和人物的心理,不写具体的性描写;剧本和分镜用遮挡、剪影、留白和声音。

|---|---|---|

| 2010 | 林晚与沈既白,新楼盘的样板间,开盘庆功宴之后 | 交易,也是两个同类终于不用装。她在样板间的镜子里看着自己,想:这里没有一样东西是真的 |

## 写作自查清单

每写完一章,按这几条检查:

1. **这个决定,换成我在他的位置,会不会也这么做?** 如果答案是“不会”,重写动机。
2. **这两个人为什么在这里遇到?** 说不出原因的相遇,删掉。
3. **这个冲突里,两边的理由我能不能各写出一段?** 写不出来的那一边,就是在强行制造矛盾。
4. **观众知道的,至少有一个角色知道吗?** 不玩信息差骗观众。
5. **有没有用到车祸、失忆、绝症、错认身世、恶婆婆、霸总?** 有就删。
6. **数字对不对?** 赔偿金额、房价、利率、刑期,按当年真实情况写,开拍前请律师和财经顾问核对。
7. **有没有替观众审判?** 叙事只呈现选择和代价,不下结论。

## 风格

- **小说:** 冷静、克制的第三人称,每章一个视角人物。句子短,细节准,情绪靠物件和动作。参考气质:《漫长的季节》的时间感,《繁花》的城市肌理。
- **剧集:** 写实。2008 年偏潮湿的黄绿,2013 年偏冷蓝,2018 年偏灰,2021–2023 年是台风夜的蓝黑和手机屏幕的白。台风戏全部用真实风雨声。
