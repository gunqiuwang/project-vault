# 《二十四节气》鹭浦一年

古风人文短剧,二十四集,一集一个节气。南宋淳熙十二年,太湖南岸的蚕桑水乡鹭浦村,八岁的阿禾从立春开始数节气,等跟漕船去临安的爹冬至回来。

| 路径 | 内容 |
|---|---|
| `episodes/00-overview.md` | 总览:设定、人物、场景、贯穿线、提示词通用块、角色锚点、动画版画风、配音声线、分集一览 |
| `episodes/ep01.md` … `ep24.md` | 每集一份:概要、分场剧本(含全部台词)、分镜表、逐镜“图/动”提示词、动画版分段提示词 |
| `site/` | 网页版。在 `site/` 下运行 `python3 -m http.server`,浏览器打开 `http://localhost:8000` |
| `tools/` | 生成器。`tools/eps/` 按季节存每集的结构化数据,`tools/bible.py` 存全剧锚点与画风;改完运行 `python3 tools/overview.py` 重新生成 `episodes/` 和 `site/`(需要 `pip install markdown`) |

全剧 24 集,326 个镜头,镜头合计 33 分半,每集 1–2 分钟(不含片头片尾)。
