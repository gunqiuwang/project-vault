# 《驿》The Last Post Station

古风人文剧情短剧,十集加一分钟尾声。唐贞元三年(787),河西已陷吐蕃,一个奉命来撤废驿站的少年书吏,在边塞小驿“苦泉驿”遇见守了一辈子的老驿长。老人领他读完满墙题诗,每一首诗、每一件旧物,都是半个世纪里一位过客的离别与归途。

世界观、人物小传和提示词规范以设定集文档为准:https://claude.ai/artifact/4tX3MbUpzQGkGqia9DccS1

## 白模预演的已知问题

`previs/yi_ep01_sc01-02_previs_v1.mp4` 和 `previs/firstframes/` 是用有问题的旧脚本渲染的:当时 `box()` 把所有方块模型(墙、门墩、房屋)做成了应有尺寸的一半,所以画面里墙偏矮、门墩悬空。`previs.py` 已修好,但还没有重新渲染。`previs2.py` 是第 3–6 场的预演脚本,尚未渲染。

渲染需要 Blender 的 Python 模块(`pip install bpy`,Python 3.11+):

```
python previs.py -- stills          # 每镜渲一帧检查构图
python previs.py -- shot 1 2 3      # 渲染指定镜头的动画帧
python assemble.py                  # 合成预演片(需要 ffmpeg)
python previs2.py -- stills 18 20b  # 第 3–6 场
```
