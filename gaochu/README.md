# 《高处》

都市群像悬疑。2008 年台风夜,工人何小川从深圳海晏府 31 层坠落。十五年后,开发商沈既白站在自己最后一座烂尾楼的 42 层边上,才知道他最信任的两个人,一直在把他往更高的地方推。

十六年,十六个讲述者,一年一章。核心三人(沈既白、林晚、何峻)永远没有自己的视角。

## 脚本

- `python3 gen_shots.py`:由镜头数据生成 `md/40-shots.md`、`md/41-shots2.md`(120 个关键镜头,每个对应一段 10 秒、2:1 的视频,附英文生成提示词)。
- `python3 build.py`:把 `md/` 下的 Markdown 渲染成 `site/` 里的 HTML 片段(需要 `pip install markdown`)。

两个脚本都在 `gaochu/` 目录下运行。
