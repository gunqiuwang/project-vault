# 剧本库

两部古风人文短剧的全部剧本材料。

| 文件夹 | 作品 | 体量 |
|---|---|---|
| [`yi/`](yi/) | 《驿》The Last Post Station:唐贞元三年,河西陷落后的边塞驿站,一个老驿长和一个来拆驿的少年书吏 | 10 集加尾声,562 个镜头 |
| [`jieqi/`](jieqi/) | 《二十四节气》鹭浦一年:南宋太湖南岸的水乡小村,八岁的阿禾数着节气等爹回家 | 24 集,326 个镜头 |

每部作品都包含:分场剧本与全部台词、分镜表、逐镜首帧与图生视频提示词、按 MiniMax H3 工作流写的动画版分段提示词,以及生成这些文件的脚本。各自的说明见文件夹里的 README。

原来的 Project Vault 项目在 `4ff71af`(v5.6.0)之前的提交历史里,需要时可以用 `git checkout 4ff71af -- .` 找回。
